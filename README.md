# 🍴 Zomato Orders & Restaurants Analysis
## Power BI Business Intelligence Dashboard

### 📌 Project Overview

This project analyzes Zomato order and restaurant data using Microsoft Power BI.

The objective is to understand restaurant performance, order trends, customer behavior, ratings, and business performance through interactive dashboards.

---

## 🎯 Business Objectives

- Analyze order performance
- Evaluate restaurant performance
- Understand customer trends
- Analyze restaurant ratings
- Identify high-performing restaurants
- Identify important business KPIs
- Create an interactive management dashboard

---

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning

---

## 📊 Key KPIs

- Total Orders
- Total Revenue
- Average Order Value
- Restaurant Count
- Average Rating
- Customer Trends
- Restaurant Performance

---

## 📈 Dashboard Features

- KPI Cards
- Bar Charts
- Line Charts
- Pie/Donut Charts
- Geographic Analysis
- Slicers
- Interactive Filters
- Drill-down Analysis

## 🔍 Analysis Performed

### Order Analysis

Analyzed order volume and trends.

### Restaurant Analysis

Compared restaurant performance using orders, ratings, and revenue.

### Customer Analysis

Evaluated customer ordering patterns.

### Rating Analysis

Analyzed restaurant ratings and performance relationships.
